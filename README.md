# Valentina & Luca Diaries — free website starter

A static editorial landing page. No purchases, advertising accounts, subscriptions, analytics, or external services are needed to run the files.

## Preview
Open `index.html` in a browser.

## Publish for free with GitHub Pages
1. Upload `index.html` and `README.md` to the root of the existing repository.
2. Open repository **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**, `main`, and `/ (root)`; save.
4. Use the URL GitHub Pages reports when deployment finishes.

## Before promoting
Replace gradient placeholder artwork with your approved original Valentina/Luca images.
Add a real contact method and privacy policy if you later add collection/analytics.
Keep AI-fiction disclosure and add affiliate disclosures before introducing paid referral links.
